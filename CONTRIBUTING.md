# Contributing to PriceLens

Thanks for helping make everyday prices easier to understand.

## Good first contributions

- Test the mobile layout on a real device and report what feels difficult.
- Improve keyboard, screen-reader, contrast, or reduced-motion support.
- Add a language or review shopper-facing copy.
- Research barcode and unit-price conventions in your country.
- Design trustworthy ways to show freshness and verification.
- Pick an unchecked item in the README roadmap and open an issue with a proposed approach.

## Development

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm install`.
3. Start the local site with `npm run dev`.
4. Make one clear change and include tests when behavior changes.
5. Run `npm run build` before opening a pull request.

## Pull requests

Keep changes small enough to review. Explain the shopper problem, what changed, how you checked it, and any accessibility or privacy implications.

## Price-data safety

Never contribute faces, payment card details, receipt identifiers, loyalty IDs, precise home locations, or data obtained by bypassing retailer access controls. Use only data you are allowed to share.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
