# Code of Conduct

PriceLens is a global community. Be welcoming, patient, constructive, and respectful across languages, locations, backgrounds, and experience levels.

Harassment, discrimination, threats, doxxing, deliberate misinformation, and the publication of personal or private data are not acceptable.

Maintainers may edit or remove contributions and restrict participation when needed to protect the community and the integrity of the project. Report conduct or privacy concerns privately to the repository maintainers.

This code applies in project spaces and when representing the project elsewhere.
